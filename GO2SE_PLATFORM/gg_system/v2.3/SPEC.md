## v2.1 增强杠杆引擎 (2026-05-04)

1. **动态杠杆系统**
   - 强信号(D>0.8) → 5x杠杆
   - 中等信号(D>0.5) → 3x杠杆
   - 普通信号(D>0.15) → 2x杠杆

   - 止盈后30%套现重新投入

   - 保证金率实时监控

   - 保证金率 < 2.5 → 🔴强制减仓
   - 保证金率 < 3.0 → ⚠️预警
   - LINK强平价实时计算

4. **自主决策流程**
   - Mirofish 1000智能体仿真
   - 打兔子D分数计算
   - 综合决策输出

### 三档监控Cron
- 每1分钟: 保证金率监控
- 每5分钟: 增强杠杆引擎
- 每10分钟: 全域扫描
