# GG v2 资金自主调配技能

## 概述
基于1000个Mirofish智能体的资金自主调配系统，自主决定现货与逐仓账户间的资金流转。

### 加权决策方程
```
D = α*(价格变化/100) + β*成本差异 + γ*Mirofish + δ*波动率 + ε*Mirofish - 紧急惩罚

参数:
- α = 0.2 (价格变化权重)
- β = 0.15 (成本差异权重)
- γ = 0.35 (Mirofish权重)
- δ = 0.15 (波动率权重)
- ε = 0.15 (Mirofish二次权重)
```

### 阈值判断
- **D > 0.15**: 执行资金调配
- **D < -0.1**: 停止/转出资金
- **-0.1 ≤ D ≤ 0.15**: 保持现状

## 调配流程

### 1. 信号扫描
- 扫描所有D > 0.6的信号
- 按信号强度排序

### 2. Mirofish决策
- 对每个信号运行1000智能体投票
- 计算资金压力分数
- 确定调配方向和金额

### 3. 加权方程验证
- 计算D值
- 与阈值比较
- 决定是否执行

### 4. 执行调配
- **TRANSFER_IN**: 现货 → 逐仓
- **TRANSFER_OUT**: 逐仓 → 现货
- **AGGREGATE**: 其他逐仓 → 目标逐仓

## 使用场景

### 强信号时(D > 0.85)
- 自动从现货转入逐仓
- 或从其他逐仓账户归集
- 仓位: 35%

### 中等信号时(D 0.75-0.85)
- 适度调配
- 仓位: 25%

### 弱信号时(D < 0.75)
- 保持不动
- 仓位: 15-20%
