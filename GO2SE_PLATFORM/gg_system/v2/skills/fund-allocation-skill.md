# GG v2 资金自主调配技能 - Hermes蒸馏版

## 版本
v2.2.0 - Hermes学习版 (2026-05-04)

## 核心决策方程

### Mirofish 1000智能体投票
```
mirofish_fund_decision(fund_pressure_score, current_balance, target_balance, volatility)
```
- 1000个智能体同时投票
- 资金压力分数评估 (0-1)
- 波动率自适应

### 加权决策方程
```
D = 0.2*(价格变化/100) + 0.15*成本差异 + 0.35*Miro + 0.15*波动率 + 0.15*Miro - 紧急惩罚
```

### 阈值判断
- **D > 0.15**: 执行资金调配
- **D < -0.1**: 停止/转出资金
- **-0.1 ≤ D ≤ 0.15**: 保持现状

## 自主调配类型

| 类型 | 条件 | 动作 |
|------|------|------|
| TRANSFER_IN | D>0.15, 现货充足 | 现货→逐仓 |
| TRANSFER_OUT | D<-0.1 | 逐仓→现货 |
| AGGREGATE | D>0.15, 现货不足 | 其他逐仓→目标 |

## Hermes蒸馏教训

### 教训1: 资金集中策略
- 问题: 分散在9个逐仓账户导致无法集中使用
- 解决: 强信号时优先集中资金到最强信号币种
- 阈值: D>0.85时触发集中操作

### 教训2: 强信号捕获
- 问题: LINK D=0.91绝佳买点被错过
- 解决: 预配置资金到目标账户
- 目标: 保持$10+在现货作为中转

### 教训3: 摩擦成本
- 实测: 卖出手续费仅0.1%
- 结论: 可以接受卖出换仓
- 建议: 弱势币可卖出换强信号

### 教训4: 账户最低余额
- 建议: 逐仓账户保持$5-10最低余额
- 原因: 避免完全空账户无法交易
- 优先: 归集到目标账户而非完全清空

## 强信号自主操作

### 触发条件
- D > 0.85
- Miro > 90%

### 操作流程
1. 显示仿真结果 (仓位%, 止盈%, 胜率%)
2. 计算预期收益和ROI
3. 检查资金是否充足
4. 资金不足时自动归集
5. 执行交易

### 仿真格式
```
🚨 强信号预警: LINK D=0.910
   📊 仿真: 仓位35% | 止盈12% | 胜率80%
   💰 预期收益: $0.91 | ROI: 17.2%
   ⚠️ 资金不足: $2.07 < $5.30
   🔧 尝试预配置...
```
