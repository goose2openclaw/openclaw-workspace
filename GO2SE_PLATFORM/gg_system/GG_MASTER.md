## 三、声纳库趋势模型

### 3.1 七维度声纳
```
     趋势 (Trend)
        ↑
   动量 (Momentum) → 波动 (Volatility)
        ↓
   成交量 (Volume) → 深度 (Depth)
        ↓
     情绪 (Sentiment)
```

### 3.2 趋势判断
| 维度 | 上升信号 | 下降信号 |
|------|----------|----------|
| 趋势 | MA多头 | MA空头 |
| 动量 | RSI>60 | RSI<40 |
| 成交量 | 放量>1.5x | 缩量<0.5x |
| 波动 | ATR上升 | ATR下降 |
| 深度 | 买卖均衡 | 偏向一方 |
| 情绪 | 贪婪>60 | 恐惧<40 |
